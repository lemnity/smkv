# SIMAKOV — комплект для сборки сайта

## Файлы
- `index.html` — живая адаптивная страница: меню, обложка, портфолио, обо мне, контакты, подвал.
- `styles.css` — все стили и мобильная адаптация. Текст и кнопки не являются частью изображений.
- `assets/portrait-original.jpg` — исходное фото без изменений.
- `assets/full-design-reference.png` — полный утверждённый визуальный референс.
- `assets/lemnity-concept.png`, `tumtipb-concept.png`, `prostyle-concept.png` — отдельно вырезанные фрагменты концепта. В них могут присутствовать встроенные надписи, это НЕ оригинальные скриншоты сайтов. Замените на настоящие изображения кейсов перед публикацией.

## Запуск
Откройте `index.html` в браузере. Для локального сервера: `python3 -m http.server 8000`, затем http://localhost:8000.

## Перед публикацией
1. В `index.html` замените `CHANGE-ME@example.com` на действующий адрес.
2. Замените концептуальные изображения проектов реальными скриншотами.
3. Проверьте тексты, опыт, ссылки и названия проектов.
4. В текущей реализации используется Manrope с Google Fonts; можно подключить лицензионный Gilroy локально.

## Примечание
Исходный сгенерированный макет — растровое изображение, поэтому восстановить из него настоящие Figma-слои нельзя. HTML и CSS пересобраны как отдельные редактируемые компоненты.

## Обновление фотографии
На обложке используется `assets/portrait-new.jpg` — фотография из предоставленного пользователем тёмного референса. Исходная фотография сохранена отдельно.
