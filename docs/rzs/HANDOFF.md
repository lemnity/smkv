# Handoff: главная rzs.ru — «Sound of the Region»

Эталон: папка `rzs/`. Открывается двойным кликом по `index.html` или через любой статический сервер.
Сборки и зависимостей нет. ТЗ — `rzs/ideas.md`.

## Структура

```
rzs/
  index.html          разметка 8 блоков, SEO-мета, JSON-LD (Organization + 5 RadioStation)
  css/tokens.css      токены: цвет, типографика, отступы, радиусы, движение; @font-face Gilroy
  css/styles.css      стили по порядку секций + адаптив + prefers-reduced-motion
  js/data.js          весь контент: станции, факты, города, новости, контакты
  js/map-data.js      контуры трёх регионов из карты rzs.ru
  js/audio.js         RZS.Radio — аудиодвижок (live-поток или демо-синтез, шум эфира, анализатор)
  js/tuner.js         RZS.Tuner — тюнер: частота, переключение, шкала, спектр, кнопки
  js/hero.js          RZS.Hero — первый экран: табло частоты, снег, шкала, пресеты
  js/app.js           шапка, reveal, счётчики, витрина станций, новости, карта, форма
  assets/logos/       логотипы РЗС и станций (с rzs.ru, webp)
  assets/img/         фото новостей и студии (с rzs.ru)
  fonts/              Gilroy 400–900, woff2
```

Скрипты подключены по порядку с `defer`: data → map-data → audio → tuner → hero → app.
Каждый модуль кладёт API в `window.RZS`.

## Контент и источники

Всё взято с rzs.ru: главная, /reklama-na-radio/, /proizvodstvo-reklamy/, /kontakty/, /novosti/.
Ничего не придумано. Где данных нет, поле пустое (например, у «Нового радио» нет цифр аудитории).

**Расхождения на исходном сайте — нужно решение заказчика:**

| Показатель | Главная | /reklama-na-radio/ | На странице |
|---|---|---|---|
| Лет на рынке | 27 | 29 | 27 |
| Слушатели | ≈ 2 млн | 900 000 ежедневно | обе (разные метрики) |
| Ретро FM, рейтинг | ТОП-5 | 6 место, ТОП-10 | не указан |

Чтобы поправить цифру, достаточно `js/data.js` (`RZS.FACTS`, `RZS.STATIONS[].figs`).

## Прямые эфиры

У каждой станции в `data.js` есть поле `stream: null`. Пока потоков нет, тюнер работает в
**демо-режиме**: мелодия станции синтезируется в браузере, бейдж показывает «Демо-режим / Демо-звук»,
под тюнером написано, что это не трансляция. Индикатор **LIVE** загорается только на настоящем потоке.

Подключение: вписать URL в `stream`.
- **MP3 / AAC** работают сразу.
- **HLS (.m3u8)** нативно играет только Safari. Для остальных браузеров нужно подключить hls.js в `startStream()` (`js/audio.js`). Без него плеер честно пишет об ошибке и переходит в демо.
- Спектр и реакция волн на звук требуют CORS-заголовка `Access-Control-Allow-Origin` на сервере потока. Без него звук играет, а визуализация переходит в спокойную анимацию.
- Ошибка потока (`error` или отказ `play()`) → демо-режим и текст ошибки в `#tNote`.

## Блоки и поведение

| # | Блок | Что делает |
|---|---|---|
| 01 | Hero `#top` (`js/hero.js`) | Большое табло приёмника: частота во весь экран, «снег» эфира и строки развёртки, красно-голубое расслоение и дрожание цифр на помехах, волна, шкала, 5 пресетов, кнопка звука. Через 0.5s после загрузки проезжает 87.5 → 101.8 за 2.6s, имя станции «собирается» из случайных букв. Это дисплей того же `RZS.Tuner`: шкала (`Tuner.scrub/release`) и пресеты hero управляют общим состоянием, поэтому hero и блок тюнера всегда показывают одну станцию. Слоган «Звучим ближе. Громче.» — строка над частотой (`h1`) |
| — | Бегущая строка `.ticker` | Между hero и тюнером: контурная частота + логотип станции на светлой плашке, между станциями знак РЗС (цвет акцента). Строка плывёт бесконечно (48s, пауза при наведении). В покое логотипы приглушены (ч/б, 55%); при наведении частота заливается цветом станции, логотип становится цветным и приподнимается с цветной тенью. Клик настраивает тюнер и прокручивает к нему |
| 02 | Тюнер `#tuner` | Частота, логотип, имя, формат, спектр, шкала, ⏮ ▶ ⏭, 5 пресетов, бейдж Демо/LIVE. При первом показе сам проезжает 87.5 → 101.8 |
| 03 | О холдинге `#about` | Текст, «лестница аудиторий» станций, 4 счётчика (стартуют при появлении) |
| 04 | Станции `#stations` | Раскрывающиеся панели (на ≤1024px — аккордеон). Клик открывает портрет и переключает тюнер. Работает и обратно: тюнер открывает панель. «Слушать в тюнере» включает звук, вторая кнопка ведёт на сайт станции |
| 05 | Рекламодателям `#business` | Заголовок «Хотите больше клиентов?» (слово в акценте, без пролистывания), 5 направлений, 6 шагов работы, продакшн-студия, CTA: текст на акценте + тёмная «панель приёмника» с телефоном и эквалайзером. **Не называть классы и id `ads*`, `adv*`, `advert*`, `banner*`, `promo*`**: блокировщики рекламы (EasyList, RuAdList, встроенный в Opera) скрывают такие элементы — так пропадал заголовок (`##.ads-title`, `###adv-title`). Перед релизом прогнать все классы и id по спискам |
| 06 | Новости `#news` | Редакционная сетка: главная + 4 с фото, остальные списком. Тег — станция или тип события. Ссылки на rzs.ru |
| 07 | География `#geo` | SVG-карта 3 регионов, 10 городов, линии сигнала из Тюмени, пульс офиса. Город на карте и кнопка в списке подсвечивают друг друга и регион |
| 08 | Контакты `#contacts` | Отделы с телефонами и почтой, форма заявки |

**Переключение станции в тюнере:** частота плавно едет к цели (650–1500ms, easeInOutCubic). По
синусу проходит «аналоговый всплеск»: шум, размытие цифр, хаотичный спектр, по экрану пробегает
световая полоса. Проезжая мимо других станций, тюнер на миг их ловит. Затем имя станции сменяется
через blur, цвет `--st` перетекает, звучит короткий щелчок захвата.

**Шкала:** перетаскивание с инерцией и доводкой до станции ближе 0.6 МГц, колесо мыши.
С клавиатуры: ←/→ на 0.1 МГц, PgUp/PgDn — соседняя станция, Home/End.

**Форма:** проверка имени (≥ 2 символа), телефона (≥ 10 цифр), почты (если заполнена).
Ошибки под полями, фокус на первое неверное поле. Отправка открывает письмо на reklama@rzs.ru
в почтовой программе — об этом написано под кнопкой. Для продакшна заменить на POST в CRM или почтовый сервис.

Горизонтального скролла нет на 390 и 1440px (проверено). Шкала 64px на МГц при ширине < 760px.

## Доступность

- Ссылка «Перейти к содержанию», семантичные `section` с `aria-labelledby`, один `h1`.
- Шкала — `role="slider"` с `aria-valuetext` («101.8 FM, Европа Плюс»). Блок станции в тюнере — `aria-live="polite"`.
- Кнопки: Play (`aria-pressed`, подпись меняется), ⏮/⏭ с `aria-label`, пресеты с `aria-pressed`, панели станций с `aria-expanded`.
- Города на карте фокусируются с клавиатуры (Enter/Space). Поля формы связаны с ошибками через `aria-describedby` и `aria-invalid`.
- `prefers-reduced-motion`: без автоанимаций, без blur, частота встаёт сразу, волны статичны.
- Звук включается только по явному действию. Media Session API: метаданные станции и кнопки ⏮ ⏯ ⏭ гарнитуры.

## Проверено

Playwright, Chrome, 1440×900 и 390×844: все секции, ⏭ в тюнере (101.8 → 104.6), Play → «Демо-звук»
и реальный спектр, клик по панели «Ретро FM» → тюнер на 105.1, пустая форма → ошибки и фокус.
Ошибок в консоли нет, все запросы успешны.

## Перед продакшном

1. **Лицензия Gilroy** на домен rzs.ru (шрифт коммерческий).
2. URL прямых эфиров и CORS на сервере потоков; для HLS — hls.js.
3. Решить расхождения в цифрах (таблица выше).
4. Бэкенд формы вместо mailto; политика обработки персональных данных и согласие под формой (152-ФЗ).
5. Новости брать из CMS (WordPress REST API текущего сайта: `/wp-json/wp/v2/posts`).
6. Ссылок на соцсети на исходном сайте нет — добавить, если они есть.
7. Логотипы станций лежат на светлых плашках, потому что исходные PNG рассчитаны на светлый фон. Если у станций есть версии для тёмного фона, заменить.
