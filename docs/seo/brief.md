# SEO-бриф simakoov.ru / SEO research brief

Единственный источник текстов для блоков «Услуги», «Как я работаю», «FAQ», мета-тегов и JSON-LD. Русский — основной язык, у каждого текста есть английский эквивалент. Тексты можно копировать дословно.

Ограничения: только факты с сайта (12+ лет, 50+ проектов, 3 страны, Тюмень, удалённо по всему миру). Никаких выдуманных клиентов, цифр, наград, отзывов и цен. Email и телефон нигде не публикуются (публичный email пока заглушка).

## 1. Методика и оговорки

- Инструментов частотности (Wordstat, Keyso и т.п.) у меня нет. Частотность ниже оценена качественно: **высокая / средняя / низкая**, это ориентир, а не измерение. Чисел нет намеренно.
- Запросы собраны по тому, как люди формулируют задачу в Яндексе и Google. Перед закупкой трафика их нужно сверить в Яндекс Вордстате.
- **Head** — короткий, широкий запрос, высокая конкуренция. **Long-tail** — уточнённый запрос (город, тип, задача), ниже частота, выше конверсия.
- Интент: **коммерческий** (ищут исполнителя), **информационный** (ищут ответ/цену/как делать), **навигационный**.
- Реалистичная стратегия: у персонального сайта нет шансов по голым head-запросам с агентствами. Ставка на связку «услуга + Тюмень», long-tail и страницу-портфолио с реальными проектами.
