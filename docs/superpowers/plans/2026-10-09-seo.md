# SEO for simakoov.ru — Implementation Plan

Goal: make https://simakoov.ru discoverable for development and design queries (Yandex first, Google second): researched copy about the services, technical SEO, crawlable content, structured data.

Spec: the user's request (2026-10-09): "для сео и поисковиков собери информацию о разработке, дизайне". No separate spec file — rulings are provisional.

## Global Constraints

- Stack: Vite + React + TS + MUI v9 + motion. `npm run build` (tsc -b && vite build) must pass with zero TS errors and no chunk-size warning.
- MUI-only primitives/icons, styling via `src/theme.ts` + `sx`. Palette: bg `#030303`, text `#f4f1ec`, muted `#8b8b87`, accent lime `#c4ee18` (theme keys `colors.gold` / `goldLight` / `goldDark`). Font Gilroy.
- All visible copy lives in `src/data/content.ts` with identical RU (`ru`) and EN (`en: Content`) shapes; RU is primary.
- Reduced motion must be respected for any new animation.
- Canonical origin: `https://simakoov.ru/`. The same build is also published to GitHub Pages under `/smkv/`; runtime asset URLs use `BASE` from `src/utils/base.ts`. Absolute SEO URLs (canonical, og:url, og:image, sitemap, JSON-LD) always point at `https://simakoov.ru/`.
- Facts only: no invented clients, numbers, awards or reviews. Use what the site already states (12+ years, 50+ projects, 3 countries, Tyumen/Russia/worldwide, roles: developer, UI/UX designer, producer, founder; projects Lemnity, Дом науки и техники, ProStyle, Sphagnum AE; clients list in `src/data/clients.ts`) and what the project sites themselves say.
- Person: Александр Симаков / Alexander Simakov, brand SIMAKOOV. Contact form posts via FormSubmit; public contact email in `contacts.email` is still a placeholder — do not publish an email in structured data.
- Commit messages: plain, no co-author trailers or AI attribution.

## Task 1: SEO research brief

Files: create `docs/seo/brief.md`.

Research (web search allowed) and write a brief in Russian with English equivalents:
- Target query clusters for Yandex/Google: website & web-app development, UI/UX design, landing pages, e-commerce, branding/identity, product/MVP — Tyumen + Russia + remote. For each cluster: 5–10 realistic queries (mark head vs long-tail), search intent.
- Recommended `<title>` (≤ 60 chars) and meta description (≤ 160 chars) for RU and EN.
- A "Services" block: 4–5 services (e.g. Разработка сайтов и веб-приложений; UI/UX-дизайн интерфейсов; Лендинги и интернет-магазины; Брендинг и айдентика; Продукт под ключ / MVP), each with a 2–3 sentence description and 3–5 deliverables, RU + EN, natural language, no keyword stuffing.
- "Как я работаю" process: 4–5 short steps RU + EN.
- FAQ: 5–6 question/answer pairs RU + EN (сроки, стоимость — без конкретных цен, стек, работа удалённо, поддержка).
- JSON-LD facts list (Person, ProfessionalService / WebSite) built only from the Global Constraints facts.
- Keywords for each existing project card (short, factual).
The brief is the single source of copy for Tasks 3–4.

## Task 2: Technical SEO

Files: `index.html`, `public/robots.txt`, `public/sitemap.xml`, `public/og-image.jpg` (generate 1200×630 from `public/assets/portrait-hero.png` + logo text on `#030303`; sharp is available in the scratchpad, not as a project dependency), `src/i18n.tsx` (keep runtime meta updates consistent).
- `<title>` and meta description from the brief (RU default); `<link rel="canonical" href="https://simakoov.ru/">`; `<meta name="robots" content="index, follow">`; theme-color kept.
- Open Graph (`og:type website`, `og:url`, `og:image` absolute `https://simakoov.ru/og-image.jpg` with width/height, `og:locale ru_RU` + `og:locale:alternate en_US`) and Twitter card `summary_large_image`.
- `apple-touch-icon` (180×180 PNG generated from the favicon look).
- JSON-LD `<script type="application/ld+json">` with `@graph`: `WebSite` (name SIMAKOOV, url, inLanguage ru), `Person` (name, jobTitle list, address locality Тюмень/RU, sameAs only for URLs that exist — none required), `ProfessionalService` (name, url, areaServed RU + worldwide, serviceType list from the brief). No email/phone.
- `public/robots.txt`: allow all, `Sitemap: https://simakoov.ru/sitemap.xml`. `public/sitemap.xml`: single URL with lastmod.
- `src/i18n.tsx`: when switching language, title/description/og tags update from `content.ts` (already partly done) — make sure they use the brief's copy and never overwrite canonical/og:url with a non-simakoov origin.

## Task 3: Services, process and FAQ sections

Files: `src/data/content.ts` (RU + EN copy from the brief), new `src/components/Services.tsx`, new `src/components/Faq.tsx`, `src/App.tsx`, `src/components/Header.tsx` nav (add «Услуги» → `#services` if it fits at 900px; otherwise drawer only).
- Services section after "Избранные проекты"… actually placed after the Hero, before Projects: h2 "Услуги" / "Services", grid of service cards (title h3, description, deliverables list), consistent with existing section headings (`sectionTitleSx`), cards like the site's dark cards with hairline borders, accent on hover; Reveal on scroll.
- Process: compact numbered steps row inside the Services section (or right below it).
- FAQ section before the footer area (after About): h2 "Вопросы и ответы" / "FAQ", MUI Accordion styled dark; also emit `FAQPage` JSON-LD for it at runtime is NOT needed (static JSON-LD in Task 2 may include FAQPage — use the RU FAQ).
- Semantic HTML: one h1 on the page (hero), h2 per section, h3 per card.
- Responsive at 1440/1024/768/390, no horizontal scroll.

## Task 4: Crawlable static fallback

Files: `index.html`.
- Inside `<div id="root">`, add static semantic HTML that React replaces on mount: h1 (hero headline text), short intro, services list (h2 + h3 + one sentence each), project names with one line + link where public, FAQ questions with answers, contact line. Visually it must not flash: style it to match the dark page (bg `#030303`, text `#f4f1ec`, Gilroy) or keep it hidden from sighted users with no CLS (e.g. visually hidden container) — crawlers must still read it. Prefer a visually-hidden block so the loader / hero design is untouched.
- Copy must match the RU content from Task 3 (taken from the brief).

## Task 5: Verify and publish

- `npm run build`; check `dist/robots.txt`, `dist/sitemap.xml`, `dist/og-image.jpg`, JSON-LD validity (parse with node), single h1, no console errors (headless check RU/EN at 1440 + 390).
- Commit and push (GitHub Pages auto-deploys); deploy to the server with the deploy script flow.
